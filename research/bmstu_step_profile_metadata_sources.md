## Точная формулировка допуска

[Официальный FAQ](https://olymp.bmstu.ru/ru/FAQ) открыт прямым GET и вернул HTTP 200. В ответе на вопрос «Кто может участвовать в олимпиаде?» организатор пишет:

> В Олимпиаде на добровольной основе принимают индивидуальное участие обучающиеся по образовательным программам основного общего и среднего общего образования.

Основное общее образование охватывает 5–9 классы, среднее общее — 10–11 классы. Поэтому в `eligibility_notes` отражены обе части без смешения: профильные задания рассчитаны на 8–11 классы, но официальный допуск начинается с 5 класса.

Это не означает наличия отдельных вариантов заданий для 5–7 классов: на проверенных профильных страницах опубликованы только категории 8–9 и 10–11 классов.

## Контроль

JSON содержит ровно шесть уникальных slug `registry-2026-27-052-01`…`registry-2026-27-052-06`, совпадающих с существующими карточками каталога. Для каждой записи заполнены только требуемые поля `slug`, `website_url`, `eligibility_notes` и `source_url`.
