# Проверка материалов: Innopolis Open Robotics и «ФЕМИДА»

Дата проверки: **26 августа 2026 года**.

## Методика

- Источником отбора служила официальная профильная страница организатора.
- Каждая добавленная файловая ссылка проверена отдельным полным `GET`: HTTP 200, `Content-Type: application/pdf`, сигнатура `%PDF-`, ненулевой размер.
- Профиль и тип материала проверены по извлечённому тексту PDF, а не только по названию ссылки.
- Публичные ссылки Cloud Mail с демоверсиями «ФЕМИДЫ» не внесены как прямые PDF: обычный `GET` возвращает HTML-оболочку. Они остаются доступными через официальный архив РГУП.

## `registry-2026-27-020-05` — Innopolis Open, робототехника

Полный GET страницы: HTTP 200, HTML, 395 051 байт. Поэтому существующая запись по этой странице должна называться **«Архив Innopolis Open по робототехнике: задания и решения»** и иметь `material_type: archive`, а не `course`.
