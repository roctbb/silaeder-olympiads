# Catalog structure enrichment — batch G

Дата проверки: **2026-08-26**. Целевой учебный год: **2026/27**.

## Задача и границы достоверности

Пакет повторно исследует три пробела партий D/E: Межрегиональную олимпиаду
школьников на базе ведомственных образовательных организаций, профиль
«Физика» Санкт-Петербургской олимпиады школьников и олимпиаду имени
П.Д. Саркисова.

Использованы только первичные официальные источники организаторов и их
регламенты. Агрегаторы не использовались. Даты из API ведомственной олимпиады
лежат в декабре 2025 — феврале 2026 года и поэтому сохранены как исходные даты
сезона 2025/26 под статусом `previous_year_estimate`. Даты 2024/25 и более
ранних сезонов не переносились. Если актуального календаря нет, этап записан с
`date_precision: tba`.

## Межрегиональная олимпиада на базе ведомственных образовательных организаций

- [Актуальное положение организатора](https://back.v-olymp.ru/wp-content/uploads/2.-%D0%9F%D0%BE%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5_%D0%91%D0%9E%D0%9E.pdf)
  разработано с учетом Порядка Минобрнауки от 16.01.2026. Оно прямо перечисляет
  пять профилей — физику, обществознание, иностранный язык, русский язык и
  биологию — и подтверждает два этапа: дистанционный отборочный и очный
  заключительный. Документ допускает школьников младше 9 класса по варианту
  9 класса; в JSON сохранен основной диапазон 9–11 классов.
- [Официальный API со списком профилей](https://back.v-olymp.ru/wp-json/custom/v2/olymps/list)
  отдельно подтверждает 9–11 классы для языковых номинаций. Аналогичные данные
  содержатся в карточках [русского языка](https://back.v-olymp.ru/wp-json/custom/v2/olymps/details?slug=russian_language),
  [обществознания](https://back.v-olymp.ru/wp-json/custom/v2/olymps/details?slug=social_studies)
  и [физики](https://back.v-olymp.ru/wp-json/custom/v2/olymps/details?slug=physics).
- Структура и форматы подтверждены информационными API для
  [иностранного языка](https://back.v-olymp.ru/wp-json/custom/v2/olymps/info/foreign_language),
  [русского языка](https://back.v-olymp.ru/wp-json/custom/v2/olymps/info/russian_language),
  [обществознания](https://back.v-olymp.ru/wp-json/custom/v2/olymps/info/social_studies)
  и [физики](https://back.v-olymp.ru/wp-json/custom/v2/olymps/info/physics).
- [Официальный API расписания](https://back.v-olymp.ru/wp-json/custom/v2/olymps/schedule)
  отдает Unix timestamps сезона 2025/26. После перевода в календарные даты без
  сдвига получены следующие окна:

| Профиль | Отборочный этап 2025/26 | Регистрация финала | Финал 2025/26 |
|---|---|---|---|
| Иностранный язык | 01.12.2025–12.01.2026 | 13–18.01.2026 | 18.01.2026 |
| Обществознание | 08.12.2025–18.01.2026 | 19.01–01.02.2026 | 01.02.2026 |
| Русский язык | 15.12.2025–09.02.2026 | 10–15.02.2026 | 15.02.2026 |
| Физика | 01.12.2025–25.01.2026 | 28.01–01.02.2026 | 01.02.2026 |
| Биология | TBA | TBA | TBA |

Биология присутствует в актуальном положении, но отсутствует в API расписания.
Поэтому профиль закрыт по классам и двухэтапной структуре, без даты.

## Санкт-Петербургская олимпиада школьников — физика

- [Официальный каталог Центра олимпиад Санкт-Петербурга](https://olymp.academtalant.ru/region)
  подтверждает существование профильной олимпиады и ведет на домен оргкомитета.
- Домен оргкомитета `www.physolymp.spb.ru` на контрольных GET не разрешался в
  DNS. Однако [официальный архивный регламент организатора](http://baseold.anichkov.ru/files/olimp/shedule-physics-city-12-13.pdf)
  доступен прямым GET 200 и подтверждает 7–11 классы, отборочный и
  заключительный этапы. Для 9–11 классов регламент описывает теоретический и
  экспериментальный туры финала, для 7–8 — устную двухчастную схему.
- Файл регламента создан в 2012 году. Поэтому из него взяты только классы и
  названия устойчивых этапов. Его месяцы и форматы не приписаны сезону 2026/27;
  оба этапа в JSON имеют TBA/unknown.

## Олимпиада имени академика П.Д. Саркисова

- [Официальная страница РХТУ](https://sarkisov-olimp.muctr.ru/) подтверждает
  участие 9–11 классов и отборочный этап.
- [Официальная страница результатов](https://sarkisov-olimp.muctr.ru/results/)
  подтверждает заключительный этап и допуск к нему победителей и призеров
  отбора.
- На первой странице остался календарь 2024/25, на странице результатов —
  материалы 2023/24. Эти даты и исторические форматы не использованы. Для
  2026/27 подтверждены только 9–11 классы и последовательность
  «отборочный → заключительный»; оба этапа оставлены TBA/unknown.
