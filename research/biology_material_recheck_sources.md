# Повторная проверка материалов: ведомственная олимпиада, биология

Проверено 26 августа 2026 года для `registry-2026-27-030-02`.

## Результат

Найден один пригодный first-party материал по биологии: [программа общеобразовательного вступительного испытания по биологии](http://academy.fsb.ru/upload/iblock/a77/pb6cpyv2bnrln4f8dfaqgsuu0l9r723u.pdf), опубликованная Академией ФСБ России.

Это **не архив заданий ведомственной олимпиады и не её демоверсия**. Документ следует показывать как дополнительный профильный syllabus для самостоятельной подготовки. Он относится именно к биологии и не подменяет её материалами физики, обществознания, русского или иностранного языка.

Рекомендуемая запись:

```json
{
  "title": "Программа вступительного испытания по биологии: темы, формат и литература",
  "material_type": "other",
  "year": 2026,
  "url": "http://academy.fsb.ru/upload/iblock/a77/pb6cpyv2bnrln4f8dfaqgsuu0l9r723u.pdf",
  "is_official": true
}
```

Тип `other` выбран намеренно: интерфейс подписывает его нейтрально как «Материал». Называть PDF курсом, архивом или заданиями прошлых лет было бы неточно.

HTTPS на `academy.fsb.ru` при проверке завершался `SSL connection timeout` до получения HTTP-кода. Проверенный HTTP URL без редиректа стабильно отдал полный PDF, поэтому в material entry использован именно он.

## Почему архив V-olymp не подходит

1. [Список профилей архива V-olymp](https://back.v-olymp.ru/wp-json/custom/v2/prev-materials/list) — `GET 200`, JSON. В нём ровно шесть slug: `russian_language`, `social_studies`, `information_security`, `foreign_language`, `cryptography`, `physics`. `biology` отсутствует.
2. Запрос `https://back.v-olymp.ru/wp-json/custom/v2/prev-materials?slug=biology&page=0&limit=100` — `GET 400`, JSON: API не допускает такой slug.
3. [Пользовательский URL с `slug=biology`](https://v-olymp.ru/prev-materials?slug=biology) возвращает `200`, но это только одинаковая для всех профилей SPA-оболочка V-olymp объёмом 1363 байта. В ней нет названия биологии, заданий или ссылок; после запуска приложения профильный API-запрос всё равно получает `400`.
4. Маршрут `prev-materials` в официальном индексе WordPress REST также задаёт enum без `biology`. Поэтому угадывание страницы или прямого файла не является подтверждением материала.

## Итоговая граница утверждения

После повторной проверки можно закрыть **material gap**, но нельзя утверждать, что найден архив прошлых лет. Корректная формулировка для сервиса: у профиля есть официальный тематический материал организатора для подготовки; задания и решения самой олимпиады по биологии организатор пока не опубликовал.
