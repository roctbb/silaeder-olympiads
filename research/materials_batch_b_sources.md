# Материалы олимпиад — batch B

Дата проверки: **2026-08-25** (Europe/Moscow).

## Объём работы

Из `data/seed/catalog.json` выбраны уникальные `family_name` у карточек с пустым `materials`, отсортированы по имени и пронумерованы с нуля. В этом отчёте обработаны только 24 семейства, для которых `index % 3 == 1`.

Итог:

- полностью подтверждены все профили у **20 из 24** семейств;
- частично подтверждены **3 семейства**: ведомственная межрегиональная олимпиада (4 из 5 профилей), Плехановская олимпиада (1 из 4 профилей), Санкт-Петербургская олимпиада (2 из 3 профилей);
- для **1 семейства** («Всероссийская олимпиада школьников по предпринимательству») содержательный публичный архив на официальном сайте подтвердить не удалось;
- в enrichment записано 15 семейных и 19 профильных связей; непроверенные ссылки не добавлялись.

## Методика проверки

Каждый URL из enrichment был открыт прямым `GET` с переходом по редиректам. Для HTML проверялись заголовок/текст страницы и наличие фактического раздела с заданиями, решениями, архивом или подготовкой. Для PDF проверены `Content-Type: application/pdf` и сигнатура `%PDF`; для ZIP — ответ на `GET Range`, `Content-Type: application/zip` и сигнатура `PK\x03\x04`.

В локальной среде Python не доверяет TLS-сертификату сетевого перехватчика, поэтому для массовой выборки использовался тот же `GET` без проверки цепочки TLS; отдельные страницы также открывались `curl`, который в этой среде получает их штатно. Это ограничение относится к среде проверки, а не к сертификатам сайтов.

## Оговорки

- `year: null` означает обновляемый многолетний архив, а не отсутствие проверки года.
- Для «Будущего Сибири» официальный сайт ведёт к Яндекс Диску организатора; в JSON оставлена first-party страница НГТУ, на которой эта ссылка подписана как «Задания прошлых лет».
- Для `v-olymp.ru` в JSON оставлены пользовательские SPA-страницы, а не служебные API URL; наличие файлов доказано отдельной проверкой официального API.
- Ссылки на сторонние агрегаторы (`olimpiada.ru`, Postupi, «Сдам ГИА» и т. п.) не использовались как материалы.
