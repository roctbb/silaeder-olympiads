# Catalog structure enrichment — batch H

Дата проверки: **2026-08-26**. Целевой учебный год: **2026/27**.

## Объём и правила доказательности

После применения базового каталога и партий D–G без классов оставались 56
карточек. Batch H заполняет классы у **45** из них; **11** карточек оставлены
без изменений как `unresolved`. Семь slug, уже закрытых batch G
(`030-01`–`030-05`, `031-01`, `071-02`), в H намеренно не включены.

Использованы только первичные источники организаторов: профильные страницы,
таблицы результатов, положения и официальные API. Классы каждого профиля
проверялись отдельно. Единый диапазон семейства применялся только тогда, когда
сам организатор прямо распространяет правило на все перечисленные профили.
Партийные даты не добавлялись. Сведения сезона 2025/26 помечены
`previous_year_estimate`; прямые сведения сезона 2026/27 — `partial`.
