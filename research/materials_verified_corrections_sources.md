# Коррекции проверки материалов от 26 августа 2026 года

После полного повторного аудита каталога две ранее сохранённые страницы перестали
надёжно открываться. Коррекции применяются отдельным последним enrichment-слоем,
чтобы исходный протокол проверки 25 августа оставался воспроизводимым.

- Для олимпиады «В мир права» страница Wix заменена на официальный архив ВГУЮ
  [«Задания и критерии прошлых лет»](https://olimp-lk.rpa-mu.ru/?p=1326).
  Реальный GET 26 августа вернул HTTP 200; на странице перечислены задания,
  ответы и критерии отборочных и заключительных этапов 2019/20–2024/25.
- Страница результатов олимпиады имени П. Д. Саркисова
  `https://sarkisov-olimp.muctr.ru/results` исключена из материалов: домен не
  разрешился при двух попытках итогового аудита. Найденный на основном домене
  РХТУ PDF с заданиями возвращает HTTP 403, поэтому он также не выдаётся
  пользователям как подтверждённо доступный. Карточка олимпиады сохраняется, но
  без ссылки на материалы до появления стабильного официального архива.

Архив Пироговской олимпиады оставлен без изменения: после сбоя DNS он повторно
открылся прямым GET с HTTP 200 и содержит сборники заданий, ответы и критерии.
