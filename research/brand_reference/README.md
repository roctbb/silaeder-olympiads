# Палитра ЛК «Силаэдр»

Источник: [презентация «цвета и логотипы»](https://docs.google.com/presentation/d/17WFq4t2TMji_w0Q_CJVa3bpcw-7PCFqSAMwpvPRBuG0/edit?slide=id.p#slide=id.p),
слайд `id.p`, проверено 25 августа 2026 года.

- `#397698` — основной синий;
- `#EACF72` — светлый жёлтый;
- `#EFA117` — оранжевый акцент;
- `#EB4F27` — красно-оранжевый;
- `#C92325` — красный для ошибок и опасных действий.

Синий используется для навигации и основных элементов интерфейса, оранжевый —
как дозированный акцент, красно-оранжевый и красный — только для срочных и
опасных состояний. В каталоге также используются нейтральные токены из локального
`school-crm`: фон `#f4f7f9`, граница `#dbe3e8`, текст `#26343d`.
