# Проверка и обогащение материалов приоритетных олимпиад

Дата проверки: **25 августа 2026 года**. Проверялись только официальные страницы организаторов и официальные архивы. ВсОШ исключена из этого файла: её архив проверяется и исправляется отдельно.

Структурированный результат: [`priority_materials_enrichment.json`](./priority_materials_enrichment.json). В нём 153 `slug`: 69 популярных/приоритетных карточек и 84 профиля пяти крупнейших ранее пустых семейств. У каждого `slug` есть хотя бы один материал.

## Итог

- 153 карточки олимпиад без ВсОШ.
- 217 связей «олимпиада → материал».
- 101 уникальный URL: все вернули HTTP 200 после редиректов и открыли содержательную страницу, а не пустую заглушку.
- 63 уже существовавших уникальных URL перепроверены; добавлено 38 новых уникальных URL.
- Для 25 профилей «Высшей пробы» теперь есть две подтверждённые страницы: профильный архив заданий/решений и отдельная профильная страница подготовки.
- Исправлен единственный пустой приоритетный профиль: общей карточке Предпрофессиональной МОШ подобраны три официальных архива актуальных направлений.
- Заполнены ещё 84 пустые карточки: «Ломоносов» (27), НТО (21), олимпиада СПбГУ (21), «Покори Воробьёвы горы!» (8) и «Физтех» (7).

## Метод проверки

1. Каждый URL загружен полностью с переходом по редиректам; зафиксированы итоговый адрес, HTTP-статус, `Content-Type` и размер ответа.
2. Для HTML проверены заголовок страницы и фактическое содержимое: годы, названия туров, слова «задания», «решения», «разбор», «критерии», «демоверсии» или «материалы для подготовки».
3. Где архив состоит из файлов, посчитаны прямые ссылки на PDF/DOCX/ZIP/PPTX/XLSX. Для архива СПбГУ дополнительно скачан контрольный ZIP (1 740 691 байт). Страницы без расширений в ссылках (МКОШП и Мёбиус) дополнительно открыты и проверены по видимому списку материалов/турниров.
4. Проверка относится к самим URL, сохранённым как материалы. Ссылки внутри архивных страниц могут изменяться организатором независимо; для продакшена нужен периодический link-check.

## Рекомендация для импорта

Материалы из JSON можно объединять с текущими по паре `(slug, url)`. Повторяющиеся семейные страницы намеренно проверялись один раз как уникальный URL, но присутствуют у каждого подходящего `slug`, потому что база хранит профили отдельными олимпиадами. При импорте технические поля `verification` можно сохранить в журнале проверки либо отбросить; поля `title`, `material_type`, `year`, `url`, `is_official` совместимы с текущими объектами материалов.
