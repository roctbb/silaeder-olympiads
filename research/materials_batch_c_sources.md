# Проверка материалов олимпиад — batch C

Дата проверки: **2026-08-25**.

Структурированный результат: [`materials_batch_c_enrichment.json`](materials_batch_c_enrichment.json).

## Объём и методика

Из `data/seed/catalog.json` выбраны уникальные `family_name` записей с пустым
`materials`, отсортированы лексикографически и пронумерованы с нуля. В этот пакет
вошли только семейства, для которых `index % 3 == 2`: 23 семейства и 55 записей.

Для каждого кандидата искался официальный сайт организатора и публичный архив
заданий, решений либо материалов для подготовки. Каждая сохранённая ссылка
проверена реальным HTTP GET с переходом по редиректам, браузерным User-Agent и
ограниченным timeout. Помимо статуса 200 проверялись тип и размер ответа,
заголовок/текст страницы и наличие содержательных ссылок на файлы или разделы
архива. HEAD сам по себе доказательством не считался. Одинаковые URL запрашивались
однократно и затем связывались с нужными профилями.

Страницы, которые возвращали только JavaScript-shell, anti-bot HTML, обрывали
соединение, не разрешались в DNS или не содержали обещанных материалов, не
добавлялись. Они перечислены в разделе unresolved.

Итог:

- подтверждено 17 семейств, 39 записей;
- добавлено 46 связей «запись — материал» по 21 уникальному официальному URL;
- unresolved: 6 семейств, 16 записей;
- сторонние зеркала и непроверенные ссылки не использовались.

## Ограничения

Проверка подтверждает доступность и содержательность страницы на указанную дату,
но не гарантирует её будущую стабильность. Для семейств unresolved URL намеренно не
попали в блоки `materials_by_family` или `materials_by_slug`; они сохранены только
как протокол проверенных официальных кандидатов. Даты и количество файлов в отчёте
получены из ответов сайтов, а не из поисковых сниппетов.
