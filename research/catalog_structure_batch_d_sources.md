# Обогащение структуры каталога — batch D

Срез источников: **26 августа 2026 года**. Машиночитаемый пакет находится в
`research/catalog_structure_batch_d.json`. Выборка была зафиксирована до начала
исследования: уникальные семейства с пустыми `grades` или `stages`, сортировка по
`family_name`, затем только элементы с `index % 3 == 0`.

## Правила фиксации

- Использованы только страницы организаторов, их регламенты и официальные
  объявления.
- Опубликованные организатором сведения 2026/27 сохранены напрямую.
- Даты 2025/26 сохранены в исходном календарном году и имеют
  `data_status=previous_year_estimate`; их проекцию выполняет builder.
- Если подтверждена структура, но нет пригодной официальной даты, этап имеет
  `date_precision=tba` и не получает придуманного диапазона.
- Профили с разными классами или расписаниями внесены через `slug`.
- Недоступность официального сайта или отсутствие читаемого регламента не
  компенсировались агрегаторами.
