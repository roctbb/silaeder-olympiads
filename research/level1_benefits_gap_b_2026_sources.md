## Что намеренно не было превращено в льготу

- Матрица СПбГУ приёма-2026 задаёт права через сочетание профиля и уровня и не содержит полных названий целевых олимпиад. По условию исследования такие строки **не использованы**.
- Страница КФУ сообщает, что победитель может получить БВИ, 100 или дополнительные баллы, но не устанавливает однозначное право для каждого точного профиля. Поэтому отдельная льгота КФУ **не создана**.
- В матрице МГУ встречаются строки `*` — «все олимпиады соответствующего уровня». Для Турнира Ломоносова по физике такая общая строка **не использована**; записано только прямое именное совпадение в матрице МФТИ.
- Семейное правило ПГНИУ для «Юных талантов» принято, потому что официальный пункт прямо называет саму олимпиаду и конкретные 10/5/2 балла, а не выводит их из уровня.

Для каждого неоднородного набора прав внутри одного вуза создана одна UX-запись `other`, чтобы не показывать пользователю несколько почти одинаковых карточек и не скрывать различия между программами.
