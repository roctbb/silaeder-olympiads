# Покрытие каталога материалами

Срез: **31 августа 2026 года**.

## Итог

- 364 карточки в каталоге, профильные материалы для подготовки подтверждены для
  **всех 364**.
- У 362 карточек есть именно задания, решения или архив прошлых лет. Для нового
  профиля ведомственной олимпиады по биологии найден официальный syllabus
  Академии ФСБ, а для ArtMasters Junior — официальные материалы подготовки.
- 93 семейства: **91** покрыто архивами полностью, **1** частично; для одного
  семейства пока подтверждены только материалы подготовки.
- Все **109 из 109** карточек, отмеченных популярными, имеют материалы.
- В seed сохранено 482 связи с 293 уникальными URL.
- Финальный независимый аудит: **293 ok, 0 broken, 0 inconclusive**.
  Из них 238 содержательных HTML-страниц, 47 PDF/ZIP с корректной сигнатурой,
  6 JavaScript-архивов, подтверждённых через официальный API и контрольное
  скачивание файла, и 2 публичных файла Cloud Mail, проверенных через файловый
  endpoint и PDF-сигнатуру.

Полный машинный протокол: [`material_link_audit.json`](./material_link_audit.json),
читаемый протокол: [`material_link_audit.md`](./material_link_audit.md).
