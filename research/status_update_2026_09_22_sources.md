# Обновление статусов — 22 сентября 2026

Проверка выполнена вечером по Москве для сезона 2026/27. Обновлены 74 карточки;
в JSON сохранены все 364 записи. Из них 363 опубликованы, одна архивная.
После учёта времени закрытия регистрация открыта у 51 карточки. Сырые 82 значения
`open` включают прошлые регистрации с `registration_closes_at`: публичный API
отображает истёкшие как закрытые, а уведомления по ним не планируются.

## Границы проверки

Сетевой обход 135 источников используется для поиска изменений, а не как
автоматическое доказательство регистрации. Результаты и недоступные адреса
зафиксированы в `status_update_2026_09_22_review.json`.

«Миссия выполнима»: новая общая ссылка lk.fa.ru/elk работает, но профильная
my.fa.ru/auth/login по-прежнему не разрешается; открытие не подтверждено.
PROD пока предлагает подписку на новости, «Мёбиус» сообщает об ожидании открытия.
Недоступные и неоднозначные источники не получили ложную свежую дату подтверждения.

Материалы не менялись: проверено равенство массивов по каждому slug с предыдущим
JSON. Исходная дата сетевого аудита материалов (5 сентября) сохранена; добавлены
отдельные сведения о применимости аудита к новому JSON, без заявления о новой
сетевой проверке материалов.
