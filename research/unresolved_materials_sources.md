# Проверка оставшихся материалов

Дата проверки: **2026-08-26** (Europe/Moscow).

Структурированный результат: [`unresolved_materials_enrichment.json`](./unresolved_materials_enrichment.json).

## Методика

Для каждого кандидата выполнен прямой `GET` с переходом по редиректам. У HTML проверены не только код ответа и заголовок, но и фактический текст раздела. Для официального API ведомственной олимпиады дополнительно проверены опубликованные enum профилей, список архивов и список дистанционных курсов. Материалы другой олимпиады по тому же школьному предмету не использовались как подмена профильного архива.

## Всероссийская олимпиада школьников по предпринимательству — технологическое предпринимательство

Добавлен официальный курс:

- URL: `https://dream-create.ru/shkola2.html`;
- прямой `GET`: `200`, финальный URL не изменился;
- `Content-Type`: `text/html; charset=UTF-8`;
- размер распакованного тела: **32 595 байт**;
- семантическая проверка: заголовок страницы — «Курсы — Всероссийская олимпиада школьников по предпринимательству “Мечтай-создавай”». На странице есть чек-лист идеальной заявки, материал о работе с наставником и отдельный 22-минутный вебинар «Технологические инициативы — как упаковать инновацию». Его описание прямо говорит о связи технической идеи с бизнес-логикой, технологии как решении проблемы из кейса, реализуемости и масштабировании.

Страница размещена на том же официальном домене, что и карточка олимпиады, и в её подвале указаны инициатор — Минобрнауки России и оператор — АНО «ЦРИТ “ИТ-Планета”». Поэтому материал отмечен `is_official=true` и привязан именно к профилю технологического предпринимательства.

Дополнительно проверена ссылка страницы `https://dream-create.ru/upload/presentation.pptx`: `200`, `application/vnd.openxmlformats-officedocument.presentationml.presentation`, **406 489 байт**, сигнатура `PK\x03\x04`, корректная структура OOXML. Однако это шаблон трека социального предпринимательства; к технологическому профилю он намеренно не добавлен.

## Межрегиональная олимпиада на базе ведомственных образовательных организаций — биология

Материал **не добавлен**, потому что биология появилась только в проекте Перечня 2026/27, а профильный архив организатор ещё не опубликовал.

Проверено:

1. `https://back.v-olymp.ru/wp-json/custom/v2/prev-materials/list` — `200`, JSON, **781 байт**. Список содержит русский язык, обществознание, компьютерную безопасность, иностранный язык, математику и криптографию, физику; биологии нет.
2. `https://back.v-olymp.ru/wp-json/custom/v2/prev-materials?slug=biology` — `400`, официальный API сообщает `rest_invalid_param`: значение `biology` не входит в разрешённый enum профилей.
3. `https://back.v-olymp.ru/wp-json/custom/v2/archive/subjects` — `200`, JSON. В архиве задач доступны иностранный язык, компьютерная безопасность, математика и криптография, русский язык и физика; биологии нет.
4. `https://back.v-olymp.ru/wp-json/custom/v2/distance-education/courses` — `200`, JSON. Просмотрены названия всех опубликованных курсов; курса по биологии нет.
5. Зеркало Postupi `https://msk.postupi.online/olimpiada/vedomstvennaya-olimpiada-shkolnikov/zadanija/` — `200`, HTML Windows-1251, **110 684 байта**. Оно содержит 84 задания по девяти уже проводившимся предметам/языкам, но фильтра и заданий по биологии нет. Поэтому семейную страницу нельзя выдавать за материал нового биологического профиля.

Вывод: на дату проверки профиль является новым и прошлых профильных заданий фактически нет. До появления биологии в официальном API `v-olymp.ru` карточка должна честно показывать отсутствие опубликованных материалов, а не ссылку на чужую олимпиаду или другой профиль.
