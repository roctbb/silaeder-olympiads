# Дополнительный поиск материалов: группа A

Дата проверки: **26 августа 2026 года** (Europe/Moscow).

Структурированные данные: [`materials_gap_a_enrichment.json`](./materials_gap_a_enrichment.json).

## Методика

- Использовались только первичные сайты организаторов и ссылки, опубликованные в их официальных страницах или API.
- Каждый пользовательский URL проверен прямым `GET` по HTTPS с обычной проверкой TLS и переходом по редиректам.
- Для HTML проверялись не только статус и заголовок, но и фактическое содержимое страницы.
- Для PDF проверялась сигнатура `%PDF`; для DOCX — ZIP/OOXML-сигнатура `PK`.
- Материал другого профиля той же олимпиады не использовался как замена.

## «Архитектура и искусство» — `registry-2026-27-003-01`

Уже сохранённый [официальный раздел ЮРМОШ](https://raai.sfedu.ru/Olimpiada/Olimpia.html) оказался не общим лендингом, а полноценным материалом для подготовки:

- `GET 200`, `text/html; charset=UTF-8`, **275 781 байт**;
- в исходном HTML есть интерактивные задания и критерии оценивания для рисунка, живописи, композиции и черчения, распределённые по этапам и группам классов;
- галерея лучших работ получает списки через официальные `image/works/{subject}/{class}/list.php`: проверены все 15 сочетаний трёх предметов и пяти классов, каждый endpoint вернул `200 application/json`, суммарно опубликовано 93 позиции;
- контрольное изображение лучшей работы открылось с `200 image/png`, **88 777 байт**, сигнатура `\x89PNG\r\n\x1a\n`.

Это корректировка метаданных существующей ссылки: вместо `course`, `year=null` следует использовать `archive`, `year=2026` и заголовок «Задания, критерии и лучшие работы ЮРМОШ 2025/26». В текущем `scripts/build_catalog.py` функция `merge_materials()` делает upsert по URL и накладывает новые поля поверх старых; так как файл `materials_gap_a_enrichment.json` сортируется после `materials_batch_a_enrichment.json`, отдельная replace-семантика сейчас не требуется.

## «Иннагрика», агрогенетика — `registry-2026-27-006-01`

Найден отдельный [официальный архив заданий и работ победителей](https://innagrika.ru/olimpiada/zadanija-i-pobediteli-proshlyh-let/), которого не было в карточке:

- `GET 200`, `text/html; charset=UTF-8`, **381 699 байт**;
- семь сборников по трём профилям и сезонам 2023/24–2025/26;
- у агрогенетики есть отдельные сборники за три сезона;
- на той же странице опубликовано 145 ссылок на работы победителей и призёров по профилям, классам и сезонам.

Дополнительно добавлен прямой [сборник заданий и критериев по агрогенетике 2025/26](https://innagrika.ru/wp-content/uploads/2026/05/7.materialy_zadanij_i_kriterii_ocenki_profil_agrogenetika_2025-26.pdf). Он указан именно в агрогенетическом разделе официального архива. Потоковый `GET` вернул `200 application/pdf`, `Content-Length: 85 898 518`, начало файла — `%PDF-1.3`.

Существующая страница `https://innagrika.ru/olimpiada/` остаётся полезным курсом: на ней действительно есть лекции и интерактивный тест из 32 заданий отборочного этапа 2024 года. Новые ссылки дополняют её профильным архивом, а не заменяют.

## Олимпиада по предпринимательству — технологическое предпринимательство — `registry-2026-27-079-01`

В открытом официальном API пространства второго сезона на Braim (`GET https://challenge.braim.org/api/challenge/api/v1/challenge/625`) найдено реальное задание второго этапа «Предпринимательская инициатива». Сам организатор указывает в нём [публичный комплект задания](https://disk.360.yandex.ru/d/bP7LfOrVlE3khg).

Проверка пользовательской ссылки:

- `GET 200`, `text/html; charset=utf-8`, **86 780 байт**;
- официальный публичный API Яндекс.Диска вернул папку «Второй этап: Задание 1» и пять файлов:
  1. инструкция по заполнению предпринимательской инициативы — PDF, 183 359 байт;
  2. заполняемый шаблон — DOCX, 18 605 байт;
  3. критерии оценки второго этапа — PDF, 133 457 байт;
  4. кластеры и направления инициатив — PDF, 1 232 128 байт;
  5. пояснение, как работать с кластерами — PDF, 1 154 495 байт.
- все пять конечных файлов скачаны прямым `GET 200`; четыре PDF имеют корректную `%PDF-1.x`, DOCX — `PK/OOXML`, размеры полностью совпадают с метаданными API;
- комплект относится к сезону 2025/26, который является ориентиром для 2026/27, и включает кластер технологических инициатив.

Существующий [курс и вебинары](https://dream-create.ru/shkola2.html) также перепроверен: `200`, **32 595 байт**, на странице присутствуют чек-лист заявки и отдельный вебинар о технологических инициативах. Он остаётся материалом типа `course`; новый комплект добавляется как `tasks`.
